# Ranking semanal de ações — pipeline de dados

Projeto reproduzível para tratar extrações diárias da Economatica e, em uma etapa posterior, gerar análises semanais de ações. A entrada, a data de referência e o diretório de saída são parâmetros; nenhuma semana ou ação é codificada como caso especial.

O CSV original e o enunciado do processo seletivo ficam fora do repositório. As transformações, regras de qualidade, testes e premissas serão versionados aqui.

**Estado:** estrutura inicial do repositório. A etapa de ETL está em implementação.
